# TripMap · 多日行程路线地图

把想去的地方，连成一段旅程。

TripMap 是一款在地图上安排多日旅行的本地应用。按天组织地点时间线，搜索和收藏地点，拖动调整游览顺序，选择驾车、步行、骑行或地铁，计算交通与停留时间，再把行程导出分享。

支持 **Windows 安装版、免安装便携版和本地网页版**。计划自动保存，下次打开即可继续上次的旅行。

[下载最新版](https://github.com/YHonc/trip-map/releases/latest) · [更新记录](CHANGELOG.md) · [使用说明](桌面版使用说明.md) · [反馈问题](https://github.com/YHonc/trip-map/issues)

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 多计划管理 | 为不同旅行建立计划，在列表中切换、重命名和删除 |
| 地点时间线 | 按天展示「地点 → 交通方式 → 地点」，设置城市、出发时间和每站停留时间 |
| 手动计算行程 | 调整完成后点击「计算行程」，统一查看路程、交通耗时与预计到达／离开时间 |
| 地图搜索与选点 | 搜索目的地，单击地图地标查看详情，双击选择精确位置 |
| 地点收藏 | 单独收藏或一键收藏当天全部地点；已加入计划的收藏自动收起 |
| 多种出行方式 | 选择驾车、步行、骑行或地铁，查看相邻地点间的距离与时间 |
| AI 路线助手 | 按时间、距离或自定义要求优化，指定起终点与先后顺序，预览后应用 |
| 自定义提示词与攻略 | 保存旅行偏好，补充本次优化要求；直接输入、选择或拖入 TXT，建立各计划的攻略库 |
| 地图缓存与 API 用量 | 复用已查询的地图结果，查看今日、累计及各类接口的本机调用次数 |
| 自动保存与浏览记忆 | 保存计划，恢复上次选择的日期、路线及地图位置和缩放 |
| 行程导入导出 | 支持精简 JSON、批量匹配地点和 AI 整理文字攻略，导出 JSON 或含底图的 PNG／SVG |
| 地图批注 | 画线、圈选、换色、擦除和撤回，按计划保存到当前浏览器 |

编辑支持撤销／重做，路线可以单独显示或隐藏。蓝、洋红、青绿和紫等路线配色搭配白色描边，地图和导出图片都更容易辨认。地图详情卡片和可收起的路线图例，让选点与查看路线更方便。

**v1.4.0 更新**：地点时间线与手动计算行程、地铁路线、地图批注、当天批量收藏，以及精简导入和 AI 整理攻略。地图业务数据默认缓存 3 天。[查看本版更新](docs/releases/v1.4.0.md)。

## 快速上手

### 下载后直接使用

前往 [GitHub Releases](https://github.com/YHonc/trip-map/releases/latest)，选择适合你的版本：

| 版本 | 启动方式 |
| --- | --- |
| **Setup 安装版** | 运行安装程序，安装后从桌面快捷方式打开 |
| **Portable 便携版** | 下载 exe 后双击运行，免安装 |
| **Web 网页包** | 解压 ZIP，运行 `Start-Web.cmd`，打开 [127.0.0.1:32145](http://127.0.0.1:32145) |

以上版本均内置运行时，无需另行安装 Node.js。桌面版还可以通过「文件 → 在浏览器中打开」使用同一个计划库。

首次使用会创建空白计划。无需 API Key 即可体验 Mock 演示模式；启用真实地图后，就能搜索地点、选择地图地标并规划道路路线。

### 启用高德地图

打开顶部「地图设置」，选择高德模式，填写以下配置并保存：

| 配置 | 对应内容 |
| --- | --- |
| JS API Key | 高德 Web 端（JS API）Key |
| 安全密钥 | 与 JS API Key 配套的安全密钥 |
| Web 服务 Key | 高德 Web 服务 Key，用于搜索、地点详情与道路规划 |

配置保存后立即应用。申请与配置方法可参考[高德 JS API 文档](https://lbs.amap.com/api/jsapi-v2/guide/abc/load)和[高德 Web 服务文档](https://lbs.amap.com/api/webservice/summary)。

在「缓存与数据」中调整缓存容量和有效期；在「API 用量」中查看今日、累计及搜索、路线、图片导出等接口的调用次数。用量跨重启保留，清理地图缓存也会保留记录。这里统计本机服务请求；账号额度与浏览器直连底图用量可在高德控制台查看。

### 从源码运行

准备 **Node.js 22 LTS（22.12+）** 和 npm：

```bash
git clone https://github.com/YHonc/trip-map.git
cd trip-map
npm ci
npm run dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。Windows 安装依赖后，也可以双击项目中的 `Start-TripMap-Dev.cmd`，服务就绪后会自动打开浏览器。

从源码启动桌面版可使用 `Start-TripMap.cmd`，脚本检测源码变化后按需重建。开发入口支持 `-Port 3001` 指定端口，重复打开会复用同一项目的调试服务。

## 使用流程

### 1. 创建旅行计划

点击左上角的计划名称，选择「新建旅行计划」，给这次旅行起个名字。以后可以在同一列表中切换计划，每行右侧提供重命名和删除操作。

### 2. 安排日期、城市与路线

在侧栏按天组织行程，为日期或路线设置城市，添加地点。每天显示连续的地点时间线，可以保留上午、下午等路线分组；隐藏地点或空分组会被跳过，连接最近的可见地点。

### 3. 找到想去的地方

可以使用地点搜索，也可以直接在高德地图上选点：

- **单击地标**：查看该地点的官方名称和地址。
- **双击地图**：选择精确位置并查看地址。
- **收藏**：把暂时还没排入行程的地点留在收藏篮，也可从日期菜单选择「收藏当天全部地点」。已加入当前计划的收藏会变灰并紧凑收起，点击可展开地址。
- **加入行程**：选择日期与路线，把地点加入计划。

### 4. 调整安排并计算行程

拖动地点调整顺序，选择相邻地点之间的驾车、步行、骑行或地铁方式。地铁会结合城市匹配地铁与步行接驳方案；没有可用方案时可以切换交通方式。

设置每天的出发时间和每站停留时间。新加入的地点默认停留 30 分钟，可快捷选择 15／30／45／60 分钟或自定义。调整后点击「计算行程」，统一查看当前可见行程的距离、交通耗时及预计到达／离开时间。编辑只标记待计算，原手填时间继续保留。

想尝试另一种顺序，可打开「AI 路线助手」，在「AI 配置」中填写 OpenAI 兼容接口地址、模型和 API Key。生成建议后，查看前后道路成本与变化，再选择应用。

在「自定义提示词」中保存常用的旅行偏好。优化目标可选时间、距离或「自定义」；选择自定义后填写本次要求，结合预览中的路程比较决定是否应用。固定起终点默认关闭，开启后选择具体地点；「保留地点先后顺序」可单独设置。优化当天行程时可调整路线顺序，地点仍留在原路线。

「攻略参考库」支持直接输入或粘贴正文、选择 TXT 文件上传，以及拖入 TXT 文件。每个计划有独立参考库，资料可预览和删除，文本草稿在切换页签后保留。开启「参考攻略」并勾选资料，建议预览会展示实际参考的相关段落。AI 面板切换时保持外框高度，长内容在面板内滚动。

### 5. 在地图上标注想法

打开地图批注，使用画线、圈选、颜色、橡皮和撤回工具。左键使用当前工具，右键拖动地图，中键连续擦除，滚轮缩放；结束时选择「保留并关闭」或「清除并关闭」。批注按计划和地图模式保存在当前浏览器，不包含在行程 JSON 或地图图片导出中。

### 6. 导入、保存与分享

编辑会自动保存。下次打开时恢复上次计划和地图浏览位置；没有浏览记录时，优先定位计划城市或已确认地点。

在「导入 / 导出」中，用 JSON 备份和迁移计划，或导出含地图底图的 PNG 规划图、SVG 路线图用于分享。导入时按日期配色，地点名称、地址、时间和备注分别保存。精简 JSON 可省略 ID 等字段，由应用补齐。

还没确定日期或地点位置，也可以先导入：空日期显示为「日期待定」。「一键匹配并导入」按名称和地址匹配高德地点，歧义项留待确认。「AI 检查并整理」可整理 JSON 或文字攻略，预览并采用后再导入，也可恢复原文。格式与示例见[行程格式说明](docs/itinerary-format.md)。

攻略库和自定义提示词随本机数据保存；换电脑时，按[数据备份与迁移说明](桌面版使用说明.md#数据与缓存)复制完整数据目录。

重新打开页面会恢复有效的行程计算结果。城市、地点搜索与详情、驾车、步行、骑行和地铁默认缓存 3 天，优先复用浏览器结果，再读取本机 SQLite 缓存。有效期可在设置中调整，过期行程由下次点击「计算行程」更新。只改变停留或出发时间时可复用有效路段，本地顺延时间；底图图片由高德 SDK 与浏览器的 HTTP 缓存管理。
