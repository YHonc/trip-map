# 路线选项与收藏交互

隐藏、空分组会被可见行程跳过。下一个地点连接最近的可见地点；恢复显示后重新插入连接。更改模式、隐藏或拖动均不自动调用路线接口，仍由「计算行程」触发。

新增 subway（地铁）：使用高德 v3 公交综合路径规划，按所选当天/路线城市请求，筛选仅由地铁线路与步行接驳组成的完整候选，取预计总时长最短的一条。时间采用接口总时长，距离累计地铁和步行部分。不将普通公交、火车或估算直线冒充地铁；没有合适候选时提示更换交通方式。城市加入所有地铁缓存键和计算指纹，默认复用三天。旧版缓存设置自动补上地铁分类，不覆盖已有自定义期限。

AI 优化目标包含时间、距离、自定义。仅选择自定义时显示本次要求；自定义候选仍需通过地点、约束与路线核验，但不以耗时/距离变短作为唯一应用条件。固定起点和固定终点默认关闭，开启后从当前范围选择具体地点。它们约束整个所选范围的首尾；当天范围允许调整路线顺序，地点仍保留在原路线。范围变更清空所选地点；隐藏和空路线不参与。服务端也校验起终点，不依赖模型自觉遵守。

日期菜单「收藏当天全部地点」包含隐藏地点，按地点标识/高德 POI 去重，一次提交可撤销。收藏卡片宽度最多 246px，已在当前计划中的地点使用灰色 46px 折叠样式，可展开地址。拖入行程、删除和撤销后均从当前数据重新判断状态，刷新也保留正确状态。

## 公开参考

- [高德路径规划](https://lbs.amap.com/api/webservice/guide/api/direction)：公交综合路径的 city、transits、segments、walking 和 buslines 字段；v3 没有纯地铁策略，需筛选候选。
- [RouteXL Quick guide](https://docs.routexl.com/index.php?title=Quick_guide)：指定出发地点、添加目的地，再显式计算路线。
- [RouteXL Edit location](https://docs.routexl.com/index.php?title=Edit_location)：通过地点下拉框设置先后访问约束；借鉴明确选地点的交互，不照搬界面。自定义目标的条件展开根据本应用需要设计。

## 核验

隔离测试覆盖地铁候选筛选、城市缓存隔离、显式首尾约束、自定义要求、隐藏恢复连接、本地时间和批量收藏去重。浏览器使用内存行程与模拟接口，验证自定义候选应用、撤销、恢复交通选择、地铁计算、批量收藏及实际鼠标拖拽后的折叠。真实高德服务可达性取决于用户密钥和城市线路覆盖；本轮未消耗真实地图或 AI 请求。
