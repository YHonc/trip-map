# 地图批注

点击地图右上方「批注」，可使用画线、圈选、橡皮，以及三种颜色。选择「移动」后可拖动或缩放地图，批注随地理位置移动；Esc 取消当前笔画并切换到移动模式。

编辑期间左键使用当前工具，右键按住拖动地图，中键按住擦除经过的线条或圈线。右键、中键为临时操作，松开后仍保留当前工具；滚轮可以缩放地图。

- 「保留并关闭」退出编辑，保留地图上的笔迹，下次打开继续恢复。
- 「清除并关闭」移除当前行程的全部批注及其保存记录。
- 「撤回一笔」删除最近一条笔迹；橡皮可点击某条线单独删除。

批注按行程、地图模式分别保存于当前浏览器，不加入行程 JSON 或地图导出，不发起地图 API 请求。保存失败会明确提示。每个行程最多 80 条批注，每条画线最多 500 个采样点；长笔画会降采样。

笔迹保存地理坐标，渲染时转换为当前地图容器坐标。视角变化或手势取消时丢弃尚未完成的笔画；编辑时关闭高德选点及进行中的地点查询，避免绘制误触发搜索。
