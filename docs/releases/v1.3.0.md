TripMap 1.3.0 让 AI 规划结合你的旅行偏好与攻略笔记，路线更清晰，地图调用情况也一目了然。

## 本版更新

- **每个计划都有攻略参考库**：导入 TXT 景点笔记或游览经验，随时预览、删除；优化路线时勾选本次资料，查看建议实际参考的相关段落。
- **自定义 AI 提示词**：在与「AI 配置」并列的页面保存旅行节奏、交通偏好和安排原则，支持恢复默认。
- **路线更容易辨认**：蓝、洋红、青绿和紫等配色搭配白色描边，选中路线加粗；地图与 PNG／SVG 导出保持一致。
- **新增地图 API 用量页**：在「地图设置 → API 用量」查看今日、累计及搜索、道路规划、静态地图导出等分类次数。记录跨重启保留，清理地图缓存也会保留用量，缓存命中与合并请求不重复计数。

## 选择下载版本

| 文件 | 使用方式 |
| --- | --- |
| `TripMap-Setup-1.3.0-x64.exe` | 安装版，安装后从桌面快捷方式打开 |
| `TripMap-Portable-1.3.0-x64.exe` | 便携版，双击运行，免安装 |
| `TripMap-Web-1.3.0-x64.zip` | 网页版，解压后运行 `Start-Web.cmd`，打开 [127.0.0.1:32145](http://127.0.0.1:32145) |

三个版本均适用于 Windows x64，内置运行时，无需另行安装 Node.js。同页提供 `SHA256SUMS.txt` 校验文件。

## 试试攻略辅助规划

1. 打开或创建旅行计划，按天安排城市、地点与路线。
2. 打开「AI 路线助手」，在「AI 配置」填写接口、模型和 API Key。
3. 在「自定义提示词」保存旅行偏好，在「攻略参考库」导入当前计划的 TXT 笔记。
4. 回到「优化路线」，开启「参考攻略」并勾选资料。生成建议后，比较道路成本和参考片段，再选择应用。
5. 在「地图设置 → API 用量」查看本机调用情况；账号额度与浏览器直连底图用量可在高德控制台查看。

## 升级与迁移

等待计划保存并关闭旧程序，再安装或打开新版，已有计划、收藏和地图配置会继续保留。攻略资料按计划保存在本机，自定义提示词由各计划共用。换电脑时复制完整数据目录即可一并迁移；JSON 继续用于行程与收藏的备份。
