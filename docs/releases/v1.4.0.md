TripMap 1.4.0 把每天的安排串成地点时间线，加入手动计算行程、地铁路线和地图批注，让交通、停留与游览顺序一起规划。

## 本版更新

- **地点时间线与手动计算**：按「地点 → 交通方式 → 地点」查看每天的安排。设置出发时间和各站停留时长，点击「计算行程」统一获得距离、交通耗时及预计到达／离开时间。新地点默认停留 30 分钟，支持快捷调整和自定义；隐藏或空分组自动跳过。
- **三天缓存与结果恢复**：城市、地点搜索与详情、驾车、步行、骑行和地铁默认缓存 3 天，可在设置中调整。重新打开恢复有效计算结果；只改停留或出发时间时，复用有效路段并顺延时间。
- **地铁出行**：按城市查询地铁与步行接驳方案，选取总耗时最短的完整候选。无可用方案时提示切换方式。
- **更灵活的 AI 优化**：支持时间、距离和自定义目标；自定义目标按旅行要求生成建议，预览路程后决定是否应用。固定起终点默认关闭，开启后选择具体地点；当天优化可调整路线顺序，保留地点所属路线。
- **地图批注**：支持画线、圈选、换色、橡皮和撤回；右键拖动、中键擦除、滚轮缩放。批注按计划和地图模式保存到当前浏览器，不包含在 JSON 或地图图片导出中。
- **收藏与地图交互**：一键收藏当天全部地点，包含隐藏地点并自动去重，支持一次撤销。已加入计划的收藏紧凑折叠；点击地点时仅作必要平移，避开搜索、收藏和批注面板。
- **导入与攻略整理**：日期、地点和路线的时间与备注独立保存；精简 JSON 自动补齐 ID 等字段。「一键匹配并导入」批量匹配地点，歧义项留待确认。「AI 检查并整理」支持 JSON 和文字攻略，预览后采用，可恢复原始输入。
- **界面细节**：改善地点卡片、隐藏项间距和 AI 字体显示，简化计算时间文案；地图道路方向更清晰。
- **源码启动**：桌面入口检测源码变化后按需重建，调试入口支持指定端口与复用同一项目的服务。

## 选择下载版本

| 文件 | 使用方式 |
| --- | --- |
| `TripMap-Setup-1.4.0-x64.exe` | 安装版，安装后从桌面快捷方式打开 |
| `TripMap-Portable-1.4.0-x64.exe` | 便携版，双击运行，免安装 |
| `TripMap-Web-1.4.0-x64.zip` | 网页版，解压后运行 `Start-Web.cmd`，打开 [127.0.0.1:32145](http://127.0.0.1:32145) |

三个版本均适用于 Windows x64，内置运行时，无需另行安装 Node.js。同页提供 `SHA256SUMS.txt` 校验文件。

## 开始使用

1. 打开或导入旅行计划，补充城市和地点位置。
2. 拖动安排游览顺序，选择交通方式，设置每天出发时间和每站停留时间。
3. 点击「计算行程」，查看预计时间；需要另一种安排时，用 AI 助手生成并预览建议。
4. 用地图批注记录想法，或导出 JSON、PNG／SVG 分享行程。

升级前等待计划保存并关闭旧程序，再安装或打开新版。已有计划、攻略、旅行偏好和地图配置继续保留；旧版默认地图缓存期限会更新为 3 天，之后可自行调整。
