TripMap 1.2.1 让分享的行程图更完整，也让不同日期的路线更容易区分。

## 本版更新

- **导出图片带上地图底图**：修复高德模式下 PNG、SVG 缺少底图的问题。道路、地名、路线和地点一起呈现，覆盖整个行程范围；SVG 保留矢量路线与地点标记。
- **多日行程自动配色**：导入 JSON 时，为不同日期分配不同颜色，并同步当天路线。已有同色行程可以在「导入 / 导出」中重新导入当前行程完成配色。
- **使用说明更清楚**：重写 README 和发布说明，集中介绍功能、快速上手与旅行规划流程。

## 选择下载版本

| 文件 | 使用方式 |
| --- | --- |
| `TripMap-Setup-1.2.1-x64.exe` | 安装版，安装后从桌面快捷方式打开 |
| `TripMap-Portable-1.2.1-x64.exe` | 便携版，双击运行，免安装 |
| `TripMap-Web-1.2.1-x64.zip` | 网页版，解压后运行 `Start-Web.cmd`，打开 http://127.0.0.1:32145 |

三个版本均适用于 Windows x64，内置运行时，无需另行安装 Node.js。同页提供 `SHA256SUMS.txt` 校验文件。

## 开始规划

1. 打开应用，创建旅行计划，按天设置城市与路线。
2. 在「地图设置」填写高德 JS API Key、安全密钥和 Web 服务 Key，启用真实地图；也可以先体验演示模式。底图导出使用 Web 服务 Key 的静态地图接口。
3. 搜索或单击地图地标，收藏地点或加入当天路线，拖动调整顺序。
4. 在「导入 / 导出」中备份 JSON，或导出 PNG、SVG 行程图分享。

升级时等待保存并关闭旧程序，再安装或打开新版，已有计划、收藏和地图配置会继续保留。
