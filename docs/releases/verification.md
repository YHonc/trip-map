# 发布构建与核验记录

下载选择和使用步骤见各版本 Release；本文保留构建证据与核验范围。

## v1.2.1

构建日期：2026-10-01。Next.js 16.3.6、Electron 44.4.5，服务运行时为 Node 20.19.5；打包工具使用独立 Node 24，SQLite 在内置服务运行时中验证。

- 75 项隔离测试全部通过，涵盖新增静态地图接口、地图投影、SVG 内嵌底图和导入配色。
- `desktop:prepare` 完成生产构建、TypeScript 检查和 standalone 资源准备；`electron-builder` 生成 Windows x64 安装版与便携版，同一资源目录生成网页 ZIP。
- 开发版实际调用高德静态地图接口，导出 SVG 和 PNG，并目视检查底图、路线位置与日期颜色。
- 最终桌面程序验证了计划重命名、关闭前保存、重启读回、设置页和退出释放端口。
- 最终便携 exe 从源码目录外启动，PATH 不含外部 Node；界面、SQLite 保存与正常退出通过。
- 最终网页 ZIP 解压到源码目录外，使用内置 Node 启动；SQLite 数据在重启后保留，启动器退出后子服务停止。
- 成品冒烟检查使用独立临时数据目录与 Mock 模式。分发资源未包含环境配置文件、用户数据库或地图／AI 密钥配置文件。
- 三个下载包生成 SHA-256 校验值，发布时与 GitHub 附件摘要核对；校验文件随 Release 提供。

## 核验范围与运行说明

成品测试覆盖启动、存储和退出流程。真实高德服务验证与隔离测试分别记录；底图、地址和道路结果取决于配置服务与账号权限。

Windows 程序未代码签名，更新采用下载新版本的方式。尚未在干净 Windows 虚拟机执行完整安装／卸载验收，也未开展正式启动性能基准。加载进度表示准备阶段。

应用面向本机使用，高德底图在线加载。地图缓存、服务配置、用户数据位置及第三方条款见[技术与维护说明](../technical-guide.md)和[第三方声明](../../THIRD_PARTY_NOTICES.md)。
