TripMap 1.2.0 更新计划管理、地图选点和启动体验。重新打开时恢复上次浏览的计划和地图位置。

## 本版变化

- **计划管理**：展开顶部计划列表，在每行右侧重命名或删除。删除有二次确认，删除最后一个计划会创建空白计划。
- **地图选点**：单击有标志的地标查看官方地点；双击地图选取精确坐标。地点详情支持收藏和加入行程，单击空白区域不选点。
- **更紧凑的地图界面**：地点卡片调整为 240px，优化字体、地址和按钮；仅在卡片被遮挡时平移地图。路线图例支持关闭和恢复。
- **启动与加载**：并行读取配置和计划库、提前加载地图 SDK、按需加载较大的弹窗；新增阶段进度条、加载动画和失败重试。
- **记住浏览位置**：恢复上次计划、日期／路线、地图中心与缩放。无位置记录时优先显示计划城市或已确认地点，再回退全国视图；新用户从空白计划开始。
- **开发入口**：项目根目录增加桌面快速启动与源码调试脚本，补充架构导航和更新记录。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `TripMap-Setup-1.2.0-x64.exe` | Windows x64 安装版 |
| `TripMap-Portable-1.2.0-x64.exe` | Windows x64 免安装便携版 |
| `TripMap-Web-1.2.0-x64.zip` | 本地网页包，解压运行 `Start-Web.cmd`，访问 `http://127.0.0.1:32145` |
| `SHA256SUMS.txt` | 三个下载包的 SHA-256 校验值 |

成品内置运行时，无需安装 Node.js。先等待计划保存并关闭旧程序，再使用新版；默认继续使用 `%LOCALAPPDATA%\TripMap` 中的计划、收藏与配置。未配置高德时使用 Mock 模式，在「地图设置」填写自己的高德 JS Key、安全密钥和 Web 服务 Key 后启用真实地图。

计划与当前计划 ID 存在 SQLite；日期／路线选择、地图视图和图例偏好存在当前浏览器或桌面会话中。浏览器、端口或会话变化时，视图记忆分别保存。

## 核验与限制

- 应用功能已通过 69 项隔离测试；本次发布重新完成 Next.js 生产构建与 TypeScript 检查。
- 最终桌面程序验证了计划列表改名、关闭前保存、重启读回、设置页显示和退出释放端口。
- 最终便携 exe 从源码目录外启动，测试 PATH 不包含外部 Node；界面、SQLite 保存和正常退出通过。
- 最终网页 ZIP 解压到源码目录外，使用内置 Node 启动；SQLite 数据在服务重启后保留，启动器退出后子服务停止。
- 成品检查使用隔离临时目录与 Mock 模式；生成三个下载包的 SHA-256，检查分发目录没有用户数据库或密钥配置文件，并包含项目与运行时许可。
- 功能开发时实测高德地标与双击精确选点；地址及地标结果依赖高德服务、账号权限与配额。
- 启动优化尚无正式速度基准；进度条反映准备阶段，不表示网络下载字节百分比。
- 程序未签名、没有自动更新；未在干净 Windows 虚拟机执行完整安装／卸载验收。
- 底图使用高德官方在线 SDK 与浏览器正常 HTTP 缓存，不提供离线地图。地图缓存使用仍须符合服务商授权。
- 服务仅监听本机，不包含公网多用户鉴权。项目采用 MIT 许可，第三方依赖与服务按其自身条款使用。

完整使用说明见 [README](https://github.com/YHonc/trip-map#readme)，功能历史见 [CHANGELOG](https://github.com/YHonc/trip-map/blob/main/CHANGELOG.md)。
