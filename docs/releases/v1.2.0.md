TripMap 1.2.0 让计划管理和地图选点更顺手，重新打开即可继续上次的旅行。

## 本版变化

- **计划管理更方便**：点击左上角计划名称，在同一列表中切换、重命名或删除旅行计划。
- **直接在地图上选点**：单击地标查看地点详情，双击选择精确位置，再收藏或加入当天行程。
- **地图界面更协调**：缩小地点卡片，优化文字与按钮，路线图例可以随时收起和恢复。
- **启动体验升级**：优化启动加载流程，新增阶段进度条与加载动画。
- **继续上次的旅行**：记住计划、日期、路线、地图位置与缩放；首次打开优先定位计划所在城市。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `TripMap-Setup-1.2.0-x64.exe` | Windows x64 安装版 |
| `TripMap-Portable-1.2.0-x64.exe` | Windows x64 免安装便携版 |
| `TripMap-Web-1.2.0-x64.zip` | 本地网页包，解压运行 `Start-Web.cmd`，访问 `http://127.0.0.1:32145` |
| `SHA256SUMS.txt` | 三个下载包的 SHA-256 校验值 |

以上版本均内置运行时，无需安装 Node.js。升级时等待保存并关闭旧程序，再安装或打开新版，已有计划、收藏和配置会继续保留。

## 快速上手

1. 创建旅行计划，按天设置城市并添加路线。
2. 在「地图设置」填写高德 JS API Key、安全密钥和 Web 服务 Key，或先体验演示模式。
3. 搜索或点击地图地标，把地点收藏或加入行程，拖动调整顺序。
4. 下次打开继续编辑，也可以通过「导入 / 导出」备份和分享。
