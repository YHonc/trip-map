# 手动计算行程

在行程概览点击「计算行程」，统一计算当前显示地点之间的道路距离、交通耗时，以及预计到达和离开时间。拖动卡片、更改交通方式、停留时间或出发时间只标记待计算，不自动发送路线请求。

- 每段使用该段选择的步行、骑行、驾车或地铁方式；分组内的每对相邻地点也会分别显示时间和距离。
- 加入地点默认停留 30 分钟，可快捷选择 15、30、45、60 分钟，或自定义 0–1440 分钟。已有地点可在「停留时间与备注」修改。
- 旧行程未设置停留分钟时，采用原抵达与离开时间差；缺少完整时间时采用 30 分钟。
- 每天可单独设置出发时间。首次默认使用当天原开始时间、原地点时间中的最早时间，或 09:00。
- 预计时间由出发时间 + 每段交通耗时（向上取整到分钟）+ 每站停留时间顺延，可跨午夜。原手填安排保留，计算结果不覆盖它。
- 隐藏地点不参与计算；跳过隐藏或空分组，连接最近的可见地点。遇到未定位或失败路段时，不虚构之后的到达时间。
- 数字下方的眼睛只切换当前地点的显示。旧的多地点分组会在必要时拆分，其他地点和停留安排不变。

成功结果按计划及地图配置保存在当前浏览器，最多复用三天，失效后由下一次点击发起请求；路段级浏览器和 SQLite 缓存继续生效。改变停留时间或出发时间只需本地顺延，无需重新请求有效路段。重新打开页面只恢复有效结果。计算期间若修改行程，旧任务不会覆盖新的安排。

`stayMinutes` 与当天 `departureTime` 随行程存储和 JSON 导出；预计时间是本机派生结果，不写回原手填时间字段。
